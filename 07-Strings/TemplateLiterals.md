# Template Literals

## Definition

Template literals use **backticks** for strings with expressions.

## Example

```javascript
const name = "John";
const msg = `Hello, ${name}!`;
console.log(msg); // "Hello, John!"

// Multi-line
const html = `
<div>
    <h1>${name}</h1>
</div>
`;
```

## Quick Revision

- Use backticks `` ` ``
- Embed with `${expression}`
- Multi-line support
- Better than concatenation
