# TypeScript Types

## Definition

TypeScript types **define data shapes**.

## Basic Types

```typescript
let name: string = "John";
let age: number = 30;
let active: boolean = true;
let items: string[] = ["a", "b"];
let id: string | number;
```

## Quick Revision

- string, number, boolean
- Array: `type[]`
- Union: `type1 | type2`
- Any: `any` (avoid)
