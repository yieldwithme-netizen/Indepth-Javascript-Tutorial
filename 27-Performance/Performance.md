# Performance

## Definition

Performance involves **optimizing speed** and efficiency.

## Metrics

- FCP: First Contentful Paint
- LCP: Largest Contentful Paint
- FID: First Input Delay
- CLS: Cumulative Layout Shift

## Techniques

- Lazy loading
- Code splitting
- Memoization
- Debounce/throttle
