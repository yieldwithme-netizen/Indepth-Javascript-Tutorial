# Memory Management

## Definition

Memory management **allocates and frees memory**.

## How It Works

```javascript
// Allocation
const obj = { name: "John" };

// Usage
console.log(obj.name);

// Release (automatic)
obj = null;
```

## Quick Revision

- Automatic memory management
- Garbage collection frees unused memory
- Avoid memory leaks
- Use WeakMap/WeakSet
