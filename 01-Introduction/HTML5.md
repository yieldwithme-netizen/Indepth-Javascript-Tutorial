# HTML5

## Definition

HTML5 is the **latest HTML standard** with new features.

## New Features

```html
<!-- Semantic elements -->
<header>, <nav>, <main>, <section>, <article>

<!-- Media -->
<video>, <audio>, <canvas>

<!-- Forms -->
<input type="date", "email", "range">

<!-- Storage -->
localStorage, sessionStorage
```

## Quick Revision

- HTML5 = latest HTML standard
- Semantic elements
- Media elements
- Form enhancements
- Storage APIs
