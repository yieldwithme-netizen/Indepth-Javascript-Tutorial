# Set Object

## Definition

Set is a **collection of unique values**.

## Basic Usage

```javascript
const set = new Set([1, 2, 2, 3, 3]);
console.log([...set]); // [1, 2, 3]

set.add(4);
set.has(2); // true
set.size; // 4
```

## Quick Revision

- Set = unique values
- Methods: add, has, delete, size
- Removes duplicates automatically
