# Map

## Definition

Map is a **collection of key-value pairs** with any key type.

## Basic Usage

```javascript
const map = new Map();
map.set("name", "John");
map.get("name"); // "John"
map.has("name"); // true
map.size; // 1
```

## Quick Revision

- Map = key-value pairs
- Any type as key
- Methods: set, get, has, size
- Better than objects for many keys
