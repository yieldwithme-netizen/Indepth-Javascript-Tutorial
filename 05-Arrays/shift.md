# shift Method

## Definition

`shift()` removes the **first element** from an array.

## Example

```javascript
const arr = [1, 2, 3, 4, 5];
const removed = arr.shift();
console.log(removed); // 1
console.log(arr); // [2, 3, 4, 5]
```

## Quick Revision

- `shift()` removes first element
- Returns removed element
- Modifies original array
- O(n) time complexity
