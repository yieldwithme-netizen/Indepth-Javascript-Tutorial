# Sorting Algorithms

## Definition

Sorting algorithms **arrange elements** in order.

## Array Sort

```javascript
const arr = [3, 1, 4, 1, 5, 9];

// Ascending
arr.sort((a, b) => a - b);

// Descending
arr.sort((a, b) => b - a);

// String sort
arr.sort();
```

## Quick Revision

- `sort()` sorts array
- Compare function for numbers
- `a - b` ascending
- `b - a` descending
