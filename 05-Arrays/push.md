# push Method

## Definition

`push()` adds elements to the **end** of an array.

## Example

```javascript
const arr = [1, 2, 3];
arr.push(4);
console.log(arr); // [1, 2, 3, 4]

arr.push(5, 6);
console.log(arr); // [1, 2, 3, 4, 5, 6]
```

## Quick Revision

- `push()` adds to end
- Returns new length
- Modifies original array
- O(1) time complexity
