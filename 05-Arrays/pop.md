# pop Method

## Definition

`pop()` removes the **last element** from an array.

## Example

```javascript
const arr = [1, 2, 3, 4, 5];
const removed = arr.pop();
console.log(removed); // 5
console.log(arr); // [1, 2, 3, 4]
```

## Quick Revision

- `pop()` removes last element
- Returns removed element
- Modifies original array
- O(1) time complexity
