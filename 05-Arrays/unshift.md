# unshift Method

## Definition

`unshift()` adds elements to the **beginning** of an array.

## Example

```javascript
const arr = [3, 4, 5];
arr.unshift(1, 2);
console.log(arr); // [1, 2, 3, 4, 5]
```

## Quick Revision

- `unshift()` adds to beginning
- Returns new length
- Modifies original array
- O(n) time complexity
