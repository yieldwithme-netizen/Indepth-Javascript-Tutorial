# REST API Design

## Definition

REST API design defines **how APIs are structured**.

## Principles

```javascript
// Resource-based URLs
GET    /api/users
GET    /api/users/:id
POST   /api/users
PUT    /api/users/:id
DELETE /api/users/:id

// Status codes
200 OK
201 Created
400 Bad Request
404 Not Found
500 Server Error
```

## Quick Revision

- Resource-based URLs
- HTTP methods for operations
- Status codes for results
- Stateless design
