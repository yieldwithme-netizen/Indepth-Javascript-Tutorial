# What-is-WebService

## Definition

Web services are ** APIs that communicate over HTTP**.

## Types

| Type | Description |
|------|-------------|
| REST | Architectural style |
| GraphQL | Query language |
| SOAP | XML-based protocol |
| gRPC | RPC framework |

## Quick Revision

- Web services = APIs over HTTP
- REST, GraphQL, SOAP, gRPC
- JSON or XML for data
- HTTP methods for operations
