# CSS Basics

## Definition

CSS basics covers **styling fundamentals** for web pages.

## Selectors

```css
/* Element */
p { color: blue; }

/* Class */
.box { background: red; }

/* ID */
#header { font-size: 24px; }

/* Descendant */
.container p { margin: 10px; }
```

## Quick Revision

- Selectors target elements
- Properties define styles
- Values set appearance
- Classes for reusable styles
