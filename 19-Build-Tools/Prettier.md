# Prettier

## Definition

Prettier **formats code** consistently.

## Setup

```bash
npm install prettier --save-dev
npx prettier --write src/
```

## Config

```json
{
    "semi": true,
    "singleQuote": true,
    "tabWidth": 2,
    "trailingComma": "es5"
}
```

## Quick Revision

- Prettier = code formatter
- Auto-formats on save
- Consistent style
- Works with ESLint
