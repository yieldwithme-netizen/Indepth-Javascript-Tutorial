# Jest

## Definition

Jest is a **JavaScript testing framework**.

## Example

```javascript
test('adds 1 + 2', () => {
    expect(1 + 2).toBe(3);
});
```

## Quick Revision

- Jest = testing framework
- test() or it() to define tests
- expect() for assertions
- describe() for grouping
