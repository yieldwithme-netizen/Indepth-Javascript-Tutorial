# While Loop

## Definition

`while` repeats code as long as **condition is true**.

## Syntax

```javascript
while (condition) {
    // code
}
```

## Example

```javascript
let i = 0;
while (i < 5) {
    console.log(i); // 0, 1, 2, 3, 4
    i++;
}
```

## Quick Revision

- While: runs while condition is true
- Use when iterations unknown
- Always update variable
- Use break to exit
