# break Statement

## Definition

`break` **exits** a loop or switch statement.

## Example

```javascript
for (let i = 0; i < 10; i++) {
    if (i === 5) break;
    console.log(i); // 0, 1, 2, 3, 4
}
```

## Quick Revision

- `break` exits loop entirely
- Use for early exit
- Works in for, while, do-while, switch
