# Statement

## Definition

A statement is a **code instruction** that performs an action.

## Types

```javascript
// Declaration
let x = 10;

// Expression
x = x + 1;

// Control flow
if (x > 5) { }

// Loop
for (let i = 0; i < 5; i++) { }

// Function
function greet() { }
```

## Quick Revision

- Statement = code instruction
- Declaration, expression, control flow
- Statements end with semicolons
- Expressions return values
