# operator Keyword

## Definition

Operators perform **operations** on values.

## Types

```javascript
// Arithmetic
5 + 3;  // 8

// Comparison
5 === 5; // true

// Logical
true && false; // false

// Assignment
x = 10;
```

## Quick Revision

- Arithmetic: +, -, *, /, %
- Comparison: ===, !==, >, <
- Logical: &&, ||, !
- Assignment: =, +=, -=
