# iteration

## Definition

Iteration is **repeating code** over a collection.

## Methods

```javascript
// for loop
for (let i = 0; i < 5; i++) { }

// for...of
for (const item of arr) { }

// forEach
arr.forEach(item => { });

// while
while (condition) { }
```

## Quick Revision

- Iteration = repeating code
- for, for...of, forEach, while
- Use appropriate loop type
