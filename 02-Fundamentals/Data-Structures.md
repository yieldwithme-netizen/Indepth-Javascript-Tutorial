# Data Structures

## Definition

Data structures are **ways to organize and store data**.

## JavaScript Data Structures

```javascript
// Array
const arr = [1, 2, 3];

// Object
const obj = { name: "John", age: 30 };

// Map
const map = new Map();
map.set("key", "value");

// Set
const set = new Set([1, 2, 3]);

// WeakMap
const weakMap = new WeakMap();

// WeakSet
const weakSet = new WeakSet();
```

## Quick Revision

- Array: ordered list
- Object: key-value pairs
- Map: key-value with any key type
- Set: unique values
- WeakMap/WeakSet: weak references
