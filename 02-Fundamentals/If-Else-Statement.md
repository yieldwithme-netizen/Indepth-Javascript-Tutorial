# If-Else Statement

## Definition

`if-else` **executes code** based on conditions.

## Syntax

```javascript
if (condition) {
    // runs if true
} else if (condition2) {
    // runs if condition2 true
} else {
    // runs if all false
}
```

## Example

```javascript
const age = 20;
if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}
```

## Quick Revision

- `if` checks condition
- `else if` checks additional
- `else` handles default
- Always use `===`
