# if Statement

## Definition

`if` executes code when **condition is true**.

## Example

```javascript
const age = 20;
if (age >= 18) {
    console.log("Adult");
}
```

## Quick Revision

- `if` checks condition
- Runs code if true
- Use `===` for comparison
- Always use braces
