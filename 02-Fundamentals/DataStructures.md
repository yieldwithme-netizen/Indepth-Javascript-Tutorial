# DataStructures

## Definition

Data structures **organize and store data**.

## JavaScript Data Structures

```javascript
// Array
const arr = [1, 2, 3];

// Object
const obj = { name: "John" };

// Map
const map = new Map();

// Set
const set = new Set();
```

## Quick Revision

- Array: ordered list
- Object: key-value pairs
- Map: key-value with any key
- Set: unique values
