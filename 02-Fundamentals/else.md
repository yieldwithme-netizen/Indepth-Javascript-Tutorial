# else Statement

## Definition

`else` runs code when **condition is false**.

## Example

```javascript
const age = 15;
if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}
```

## Quick Revision

- `else` runs when if condition is false
- Used with `if`
- Can chain with `else if`
