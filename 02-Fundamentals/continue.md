# continue Statement

## Definition

`continue` **skips** to the next iteration of a loop.

## Example

```javascript
for (let i = 0; i < 10; i++) {
    if (i % 2 === 0) continue;
    console.log(i); // 1, 3, 5, 7, 9
}
```

## Quick Revision

- `continue` skips current iteration
- Goes to next loop iteration
- Use for filtering in loops
