# Do-While Loop

## Definition

`do-while` runs code **at least once** before checking condition.

## Syntax

```javascript
do {
    // code
} while (condition);
```

## Example

```javascript
let i = 0;
do {
    console.log(i); // 0, 1, 2, 3, 4
    i++;
} while (i < 5);
```

## Quick Revision

- Runs at least once
- Condition checked after execution
- Use for: input validation, menus
