# switch Statement

## Definition

`switch` executes code based on **exact value match**.

## Example

```javascript
const day = "Monday";
switch (day) {
    case "Monday":
        console.log("Start of week");
        break;
    case "Friday":
        console.log("End of week");
        break;
    default:
        console.log("Midweek");
}
```

## Quick Revision

- Switch checks exact value
- Use `case` for each value
- Use `break` to exit
- `default` handles unmatched
