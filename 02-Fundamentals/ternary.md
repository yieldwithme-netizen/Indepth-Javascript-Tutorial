# ternary Operator

## Definition

Ternary is a **shorthand if-else**.

## Syntax

```javascript
condition ? valueIfTrue : valueIfFalse
```

## Example

```javascript
const age = 20;
const status = age >= 18 ? "adult" : "minor";
```

## Quick Revision

- `condition ? a : b`
- Returns a value
- Shorthand for simple if-else
- Avoid nested ternaries
