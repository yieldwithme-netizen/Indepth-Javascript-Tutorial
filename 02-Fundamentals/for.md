# for Loop

## Definition

The `for` loop **repeats code** a specific number of times.

## Syntax

```javascript
for (initialization; condition; increment) {
    // code
}
```

## Example

```javascript
for (let i = 0; i < 5; i++) {
    console.log(i); // 0, 1, 2, 3, 4
}
```

## Quick Revision

- `for (init; condition; increment)`
- Use when iterations known
- `i < length` for arrays
- Always increment to avoid infinite loop
