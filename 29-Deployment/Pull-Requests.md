# Pull Requests

## Definition

Pull requests **propose changes** for review before merging.

## Workflow

```bash
# Create branch
git checkout -b feature

# Push branch
git push origin feature

# Create PR on GitHub
# Review, approve, merge
```

## Quick Revision

- PR = proposed changes
- Create branch → push → PR
- Review before merge
- Discuss changes
