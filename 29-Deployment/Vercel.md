# Vercel

## Definition

Vercel is a **hosting platform** for frontend frameworks.

## Deploy

```bash
# Install CLI
npm install vercel -g

# Deploy
vercel --prod
```

## Quick Revision

- Vercel = hosting platform
- Optimized for Next.js
- Serverless functions
- Free tier available
