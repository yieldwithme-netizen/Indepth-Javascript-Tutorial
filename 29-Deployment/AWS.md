# AWS

## Definition

AWS (Amazon Web Services) is a **cloud computing platform**.

## Key Services

- EC2: Virtual servers
- S3: File storage
- Lambda: Serverless functions
- RDS: Databases
- CloudFront: CDN

## Quick Revision

- AWS = cloud platform
- EC2, S3, Lambda, RDS
- Pay per use
- Scalable infrastructure
