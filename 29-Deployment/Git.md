# Git

## Definition

Git is a **version control system** for tracking code changes.

## Basic Commands

```bash
git init
git add .
git commit -m "message"
git push origin main
git pull origin main
```

## Quick Revision

- Git = version control
- init, add, commit, push, pull
- Branches for features
- Merge to combine
