# Git Workflow

## Definition

Git workflow defines **how teams use Git** for collaboration.

## Basic Workflow

```bash
# 1. Create branch
git checkout -b feature

# 2. Make changes
git add .
git commit -m "Add feature"

# 3. Push branch
git push origin feature

# 4. Create Pull Request
# 5. Review and merge
```

## Quick Revision

- Feature branch workflow
- Create branch → work → PR → merge
- Keep main clean
- Use meaningful commits
