# GitLab

## Definition

GitLab is a **DevOps platform** for Git hosting and CI/CD.

## Features

- Git repository hosting
- CI/CD pipelines
- Issue tracking
- Container registry

## Quick Revision

- GitLab = Git hosting + DevOps
- Built-in CI/CD
- Self-hosted option
- Similar to GitHub
