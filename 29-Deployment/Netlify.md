# Netlify

## Definition

Netlify is a **hosting platform** for static sites and serverless functions.

## Deploy

```bash
# Install CLI
npm install netlify-cli -g

# Deploy
netlify deploy --prod
```

## Quick Revision

- Netlify = hosting platform
- Static sites, serverless functions
- Git integration
- Free tier available
