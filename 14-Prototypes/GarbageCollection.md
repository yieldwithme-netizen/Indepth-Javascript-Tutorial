# GarbageCollection

## Definition

Garbage collection **automatically frees unused memory**.

## How It Works

```javascript
let obj = { name: "John" };
obj = null; // gets garbage collected
```

## Quick Revision

- Automatic memory management
- Collects unreachable objects
- Avoid memory leaks
