# What-is-Math

## Definition

Math object provides **mathematical functions**.

## Properties

```javascript
Math.PI;   // 3.14159...
Math.E;    // 2.718...
```

## Methods

```javascript
Math.abs(-5);     // 5
Math.ceil(4.3);   // 5
Math.floor(4.7);  // 4
Math.round(4.5);  // 5
Math.sqrt(16);    // 4
Math.random();    // 0-1
```

## Quick Revision

- Math.PI, Math.E constants
- abs, ceil, floor, round
- sqrt, pow, max, min
- Math.random() for random
