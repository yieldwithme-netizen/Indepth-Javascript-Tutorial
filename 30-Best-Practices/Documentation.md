# Documentation

## Definition

Documentation **explains code** for other developers.

## Types

```javascript
// Code comments
// This function adds two numbers

// JSDoc
/**
 * Adds two numbers
 * @param {number} a - First number
 * @param {number} b - Second number
 * @returns {number} Sum
 */
function add(a, b) { return a + b; }

// README
// Installation, usage, API reference
```

## Quick Revision

- Comments explain code
- JSDoc for function documentation
- README for project docs
- Keep docs updated
