# Code Style

## Definition

Code style defines **consistent coding conventions**.

## Rules

```javascript
// Naming
const userName = "John";  // camelCase
class UserAccount {}      // PascalCase
const API_URL = "...";    // UPPER_SNAKE

// Formatting
if (condition) {          // Space before brace
    statement;
}

// Semicolons
const x = 10;             // Use semicolons
```

## Quick Revision

- camelCase for variables
- PascalCase for classes
- Consistent formatting
- Use linter/formatter
