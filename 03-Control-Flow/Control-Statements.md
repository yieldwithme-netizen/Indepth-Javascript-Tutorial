# Control Statements

## Definition

Control statements **control program flow**.

## Types

```javascript
// Conditional
if (condition) { }
else if (condition) { }
else { }
switch (expr) { case: }

// Looping
for (let i = 0; i < 5; i++) { }
while (condition) { }
do { } while (condition);

// Jumping
break;
continue;
return;
```

## Quick Revision

- if/else: conditional execution
- for/while: loops
- break/continue: loop control
- return: exit function
