# Module Bundlers

## Definition

Module bundlers **combine JavaScript files** into optimized bundles.

## Popular Bundlers

| Bundler | Description |
|---------|-------------|
| Webpack | Most popular |
| Vite | Fast, modern |
| Rollup | Best for libraries |
| esbuild | Extremely fast |

## Quick Revision

- Bundlers combine modules
- Reduce HTTP requests
- Enable optimization
- Use Webpack or Vite
