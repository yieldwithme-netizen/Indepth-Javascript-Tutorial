# Conditional Operators

## Definition

Conditional operators make **decisions** based on conditions.

## Ternary Operator

```javascript
const age = 20;
const status = age >= 18 ? "adult" : "minor";
```

## Logical Operators

```javascript
// AND
true && true;    // true
true && false;   // false

// OR
true || false;   // true
false || false;  // false

// NOT
!true;          // false
```

## Quick Revision

- `? :` ternary (shorthand if-else)
- `&&` AND (both must be true)
- `||` OR (at least one true)
- `!` NOT (flips value)
