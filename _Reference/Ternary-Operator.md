# Ternary Operator

## Definition

The ternary operator is a **shorthand for if-else**.

## Syntax

```javascript
condition ? valueIfTrue : valueIfFalse
```

## Examples

```javascript
const age = 20;
const status = age >= 18 ? "adult" : "minor";

const name = user?.name ?? "Guest";
```

## Quick Revision

- `condition ? a : b`
- Returns a value
- Shorthand for simple if-else
- Avoid nested ternaries
