# What-is-Number

## Definition

Number is a **primitive type** for numeric values.

## Example

```javascript
let int = 42;
let float = 3.14;
let negative = -10;
let infinity = Infinity;
let notNum = NaN;
```

## Quick Revision

- Number: integers and decimals
- Special: Infinity, NaN
- Methods: parseInt, parseFloat
- Use typeof to check
