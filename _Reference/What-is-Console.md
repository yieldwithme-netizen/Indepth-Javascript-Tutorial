# Console Object

## Definition

The console object provides **debugging and logging** methods.

## Methods

```javascript
console.log("Info");
console.warn("Warning");
console.error("Error");
console.table([{name: "John"}]);
console.dir(user);
console.group("Group");
console.time("timer");
console.timeEnd("timer");
console.count("label");
console.clear();
```

## Quick Revision

- `console.log()` for output
- `console.table()` for tables
- `console.time()` for timing
- `console.error()` for errors
