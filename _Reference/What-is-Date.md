# What-is-Date

## Definition

Date object handles **date and time** operations.

## Example

```javascript
const now = new Date();
console.log(now);

const specific = new Date('2024-01-15');
console.log(specific.getFullYear()); // 2024
```

## Quick Revision

- Date object for dates/times
- Methods: getFullYear, getMonth
- Months are 0-indexed
