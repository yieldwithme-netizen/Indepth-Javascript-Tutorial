# Type Annotation (TypeScript)

## Definition

Type annotations **specify data types** in TypeScript.

## Basic Syntax

```typescript
let name: string = "John";
let age: number = 30;
let active: boolean = true;
```

## Function Types

```typescript
function greet(name: string): string {
    return `Hello, ${name}!`;
}
```

## Quick Revision

- Add `: type` after variable
- Functions: params and return type
- Use for: type safety
