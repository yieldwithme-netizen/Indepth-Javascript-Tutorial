# Variables

## Definition

Variables are **named containers** for storing data.

## Keywords

```javascript
var x = 10;   // function scoped
let y = 20;   // block scoped
const z = 30; // block scoped, immutable
```

## Naming Rules

```javascript
let userName = "John";    // ✅ camelCase
let _private = 10;        // ✅ starts with _
let $element = "div";     // ✅ starts with $
let 2names = "bad";       // ❌ starts with number
```

## Quick Revision

- Variables store data
- Use `const` by default
- Use `let` when reassigning
- Never use `var`
- camelCase naming
