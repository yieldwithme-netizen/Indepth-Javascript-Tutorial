# Naming Conventions

## Definition

Naming conventions are **rules for naming variables, functions, and classes**.

## Variables and Functions

```javascript
// camelCase (recommended)
let userName = "John";
function getUserData() {}
const isActive = true;
```

## Classes

```javascript
// PascalCase
class UserAccount {}
class HttpClient {}
```

## Constants

```javascript
// UPPER_SNAKE_CASE
const API_URL = "https://api.example.com";
const MAX_RETRIES = 3;
```

## Private (Convention)

```javascript
// _prefix (convention, not enforced)
const _privateVar = "private";
function _privateMethod() {}
```

## Quick Revision

- Variables/functions: camelCase
- Classes: PascalCase
- Constants: UPPER_SNAKE_CASE
- Private: _prefix
