# REST API

## Definition

REST API is an **architectural style** for designing networked applications.

## Principles

- Client-server architecture
- Stateless
- Cacheable
- Uniform interface

## HTTP Methods

| Method | Purpose | Idempotent |
|--------|---------|------------|
| GET | Read | Yes |
| POST | Create | No |
| PUT | Update | Yes |
| DELETE | Delete | Yes |

## Status Codes

| Code | Meaning |
|------|---------|
| 200 | OK |
| 201 | Created |
| 400 | Bad Request |
| 401 | Unauthorized |
| 404 | Not Found |
| 500 | Server Error |

## Quick Revision

- REST = architectural style
- HTTP methods: GET, POST, PUT, DELETE
- Status codes indicate result
- Stateless design
