# What-is-TypedArrays

## Definition

Typed arrays are **array-like objects** for binary data.

## Types

```javascript
const buffer = new ArrayBuffer(8);
const view = new Int32Array(buffer);
view[0] = 42;
```

## Quick Revision

- Typed arrays for binary data
- ArrayBuffer: raw data
- TypedArray: view
- Use for: WebGL, audio
