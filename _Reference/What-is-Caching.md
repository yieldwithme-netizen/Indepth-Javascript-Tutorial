# What-is-Caching

## Definition

Caching **stores data** for faster future access.

## Types

- Browser cache (HTTP cache)
- Service worker cache
- Memory cache (Map)
- LocalStorage

## Quick Revision

- Caching = store for reuse
- Reduces load times
- Multiple caching strategies
