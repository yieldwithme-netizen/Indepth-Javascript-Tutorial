# Development Server

## Definition

A development server serves your application **during development**.

## Popular Dev Servers

```bash
# Webpack
npx webpack serve

# Vite
npx vite

# Live Server (VS Code)
live-server

# Node.js
npx nodemon server.js
```

## Features

- Hot Module Replacement (HMR)
- Auto-reload
- Source maps
- Proxy

## Quick Revision

- Dev server for development
- Hot reload on changes
- Use Vite or Webpack
- Source maps for debugging
