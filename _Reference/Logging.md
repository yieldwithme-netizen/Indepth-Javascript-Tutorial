# Logging

## Definition

Logging outputs **information for debugging** and monitoring.

## Console Methods

```javascript
console.log("Info");
console.warn("Warning");
console.error("Error");
console.table([{name: "John"}]);
console.time("timer");
console.timeEnd("timer");
```

## Quick Revision

- `console.log()` for info
- `console.warn()` for warnings
- `console.error()` for errors
- `console.table()` for tables
