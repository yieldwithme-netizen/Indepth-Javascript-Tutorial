# What-is-Cookies

## Definition

Cookies store **small data** in the browser.

## Example

```javascript
// Set cookie
document.cookie = "name=John; expires=Fri, 31 Dec 2025 23:59:59 GMT";

// Get cookies
const cookies = document.cookie;

// Delete cookie
document.cookie = "name=; expires=Thu, 01 Jan 1970 00:00:00 GMT";
```

## Quick Revision

- Cookies: small browser storage
- Set with `document.cookie`
- Max size: ~4KB
- Use for: sessions, preferences
