# What-is-Boolean

## Definition

Boolean represents **true or false** values.

## Example

```javascript
let isActive = true;
let isLoggedIn = false;

// Truthy/Falsy
Boolean(0);      // false
Boolean("hello"); // true
Boolean([]);      // true
Boolean(null);    // false
```

## Quick Revision

- Boolean: true or false
- Truthy values convert to true
- Falsy values convert to false
- Use for flags and conditions
