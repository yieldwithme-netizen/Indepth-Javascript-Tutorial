# OOP (Object-Oriented Programming)

## Definition

OOP is a **programming paradigm** based on objects.

## Four Pillars

1. Encapsulation
2. Abstraction
3. Inheritance
4. Polymorphism

## Quick Revision

- OOP = objects + methods
- Encapsulation: data hiding
- Inheritance: code reuse
- Polymorphism: flexibility
