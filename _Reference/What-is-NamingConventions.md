# What-is-NamingConventions

## Definition

Naming conventions define **how to name** variables, functions, classes.

## Rules

```javascript
// Variables/functions: camelCase
const userName = "John";
function getUserData() {}

// Classes: PascalCase
class UserAccount {}

// Constants: UPPER_SNAKE_CASE
const API_URL = "...";
```

## Quick Revision

- Variables: camelCase
- Classes: PascalCase
- Constants: UPPER_SNAKE_CASE
- Private: _prefix
