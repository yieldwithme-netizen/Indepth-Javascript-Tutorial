# What-is-SVG

## Definition

SVG creates **scalable vector graphics**.

## Example

```html
<svg width="100" height="100">
    <circle cx="50" cy="50" r="40" fill="yellow" />
</svg>
```

## Quick Revision

- SVG = vector graphics
- XML-based
- Scalable without quality loss
- Use for: icons, charts
