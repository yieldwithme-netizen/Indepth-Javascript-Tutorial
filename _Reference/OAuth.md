# OAuth

## Definition

OAuth is an **open standard for authorization** that allows third-party apps to access user data.

## How It Works

1. User clicks "Login with Google"
2. Redirect to Google
3. User authorizes
4. Redirect back with token
5. App uses token to access data

## Quick Revision

- OAuth = authorization standard
- Third-party login
- Token-based authentication
- Use for: social login, APIs
