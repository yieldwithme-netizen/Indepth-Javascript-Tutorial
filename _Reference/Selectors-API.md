# Selectors API

## Definition

Selectors API provides **standard methods** for finding DOM elements.

## Methods

```javascript
// querySelector - first match
document.querySelector(".box");

// querySelectorAll - all matches
document.querySelectorAll("p");
```

## Quick Revision

- querySelector: first match
- querySelectorAll: all matches
- Use CSS selectors
- Returns NodeList
