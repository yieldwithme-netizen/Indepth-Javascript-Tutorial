# What-is-Web-APIs

## Definition

Web APIs are **browser-provided interfaces** for interacting with browser features.

## Common APIs

| API | Purpose |
|-----|---------|
| DOM | Manipulate HTML/CSS |
| Fetch | HTTP requests |
| Geolocation | User location |
| LocalStorage | Client storage |
| Canvas | 2D graphics |
| WebSocket | Real-time communication |

## Quick Revision

- Web APIs = browser interfaces
- DOM, Fetch, Geolocation, Storage
- Use for: browser features
