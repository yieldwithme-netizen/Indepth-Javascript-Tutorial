# Write Ternary

## Definition

Writing ternary expressions **simplifies conditional logic**.

## Examples

```javascript
// Basic
const x = condition ? "yes" : "no";

// With functions
function greet(name) {
    return name ? `Hello, ${name}!` : "Hello, Guest!";
}

// With template literals
const msg = `You are ${age >= 18 ? "adult" : "minor"}`;
```

## Quick Revision

- Use for simple conditions
- Keep it readable
- Avoid complex nesting
- Good for assignments
