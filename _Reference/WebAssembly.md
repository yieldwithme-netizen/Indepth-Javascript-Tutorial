# WebAssembly

## Definition

WebAssembly (Wasm) is a **binary format** for running code in browsers.

## Use Cases

- Games
- Video editing
- CAD applications
- Image processing

## Quick Revision

- WebAssembly = binary format
- Faster than JavaScript for heavy tasks
- Languages: C, C++, Rust
- Use for: performance-critical code
