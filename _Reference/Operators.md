# Operators

## Definition

Operators are **symbols that perform operations** on values (operands).

## Types

### Arithmetic

```javascript
5 + 3;   // 8 (addition)
5 - 3;   // 2 (subtraction)
5 * 3;   // 15 (multiplication)
5 / 3;   // 1.666... (division)
5 % 3;   // 2 (modulus)
5 ** 3;  // 125 (exponentiation)
```

### Assignment

```javascript
let x = 10;
x += 5;   // 15
x -= 3;   // 12
x *= 2;   // 24
x /= 4;   // 6
x %= 5;   // 1
x **= 2;  // 36
```

### Comparison

```javascript
5 == "5";  // true (loose)
5 === "5"; // false (strict)
5 != "5";  // false
5 !== "5"; // true
5 > 3;     // true
5 < 3;     // false
5 >= 5;    // true
5 <= 4;    // false
```

### Logical

```javascript
true && false;  // false (AND)
true || false;  // true (OR)
!true;          // false (NOT)
```

## Quick Revision

- Operators perform operations on values
- Arithmetic: +, -, *, /, %, **
- Assignment: =, +=, -=, *=, /=, %=
- Comparison: ==, ===, !=, !==
- Logical: &&, ||, !
