# What-is-SQL-vs-NoSQL

## Definition

SQL vs NoSQL compares **relational and non-relational databases**.

## Comparison

| Feature | SQL | NoSQL |
|---------|-----|-------|
| Structure | Tables | Documents |
| Schema | Fixed | Flexible |
| Query | SQL | Various |
| Scaling | Vertical | Horizontal |
| Examples | MySQL, PostgreSQL | MongoDB, Redis |

## Quick Revision

- SQL: structured, tables, relations
- NoSQL: flexible, documents, key-value
- SQL: ACID compliance
- NoSQL: eventual consistency
