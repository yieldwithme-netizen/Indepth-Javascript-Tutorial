# Virtual DOM

## Definition

Virtual DOM is a **lightweight copy** of the real DOM for faster updates.

## How It Works

1. State changes
2. New Virtual DOM created
3. Diff with previous Virtual DOM
4. Update only changed parts in real DOM

## Quick Revision

- Virtual DOM = lightweight DOM copy
- Faster than direct DOM manipulation
- Used by React, Vue
- Reconciliation process
