# Linting

## Definition

Linting **analyzes code** for errors and enforces coding standards.

## ESLint

```bash
# Install
npm install eslint --save-dev

# Initialize
npx eslint --init

# Run
npx eslint src/
```

## Quick Revision

- Linting = code analysis
- ESLint is the standard
- Catches errors early
- Enforces consistent style
