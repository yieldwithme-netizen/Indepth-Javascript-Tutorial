# Links

## Definition

Links connect pages in Obsidian for **easy navigation** between topics.

## Syntax

```markdown
[[Page-Name]]
[[Page-Name|Display Text]]
[[Folder/Page-Name]]
[[Page-Name#Heading]]
```

## Examples

```markdown
// Simple link
[[What-is-JavaScript]]

// With display text
[[What-is-JavaScript|JavaScript]]

// With folder
[[01-Introduction/What-is-JavaScript]]

// To heading
[[What-is-JavaScript#History]]
```

## Quick Revision

- `[[Page]]` creates link
- `[[Page|text]]` custom text
- `[[Folder/Page]]` with folder
- `[[Page#Heading]]` to heading
