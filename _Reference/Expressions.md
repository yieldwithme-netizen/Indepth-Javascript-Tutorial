# Expressions

## Definition

Expressions are **combinations of values, variables, and operators** that evaluate to a result.

## Types

```javascript
// Arithmetic
5 + 3;    // 8

// String
"Hello" + " World"; // "Hello World"

// Logical
true && false; // false

// Assignment
let x = 10;

// Comparison
5 === 5; // true

// Ternary
true ? "yes" : "no"; // "yes"
```

## Quick Revision

- Expression = evaluates to a value
- Arithmetic, string, logical, assignment
- Can be simple or complex
- Used in statements
