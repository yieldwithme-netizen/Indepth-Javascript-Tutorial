# Rollup

## Definition

Rollup is a **JavaScript module bundler** optimized for libraries.

## Basic Config

```javascript
// rollup.config.js
export default {
    input: 'src/index.js',
    output: {
        file: 'dist/bundle.js',
        format: 'cjs'
    }
};
```

## Quick Revision

- Rollup = library bundler
- Excellent tree shaking
- ES modules focused
- Use for: npm packages
