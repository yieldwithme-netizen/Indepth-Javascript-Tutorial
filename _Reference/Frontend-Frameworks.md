# Frontend Frameworks

## Definition

Frontend frameworks are **libraries for building user interfaces**.

## Popular Frameworks

| Framework | Description |
|-----------|-------------|
| React | Component-based, virtual DOM |
| Vue | Progressive, easy learning |
| Angular | Full-featured, TypeScript |
| Svelte | Compiler, no virtual DOM |
| Next.js | React with SSR/SSG |

## Quick Revision

- Frameworks simplify UI development
- React, Vue, Angular are most popular
- Component-based architecture
- Virtual DOM for performance
