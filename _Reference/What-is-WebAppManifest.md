# What-is-WebAppManifest

## Definition

Web app manifest defines **PWA properties**.

## Example

```json
{
    "name": "My App",
    "short_name": "App",
    "start_url": "/",
    "display": "standalone"
}
```

## Quick Revision

- Manifest = PWA config
- Defines name, icons, theme
- Required for PWA
- Link in HTML
