# Truthy and Falsy Values

## Definition

Truthy values are **evaluated as true**, falsy as false in boolean context.

## Falsy Values

```javascript
false
0
-0
0n
""
null
undefined
NaN
document.all
```

## Truthy Values

```javascript
"hello"    // true
42         // true
[]         // true
{}         // true
function(){} // true
```

## Quick Revision

- Falsy: false, 0, "", null, undefined, NaN
- Everything else is truthy
- Empty arrays/objects are truthy
