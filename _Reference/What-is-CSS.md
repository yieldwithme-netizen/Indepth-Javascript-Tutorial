# What-is-CSS

## Definition

CSS (Cascading Style Sheets) **styles** web pages.

## Example

```css
/* Element */
p { color: blue; }

/* Class */
.box { background: red; }

/* ID */
#header { font-size: 24px; }
```

## Quick Revision

- CSS = styling language
- Selectors target elements
- Properties define styles
- Classes for reusable styles
