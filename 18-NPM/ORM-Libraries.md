# ORM Libraries

## Definition

ORM libraries **map objects to database** tables.

## Popular ORMs

| Library | Database |
|---------|----------|
| Sequelize | PostgreSQL, MySQL |
| Mongoose | MongoDB |
| Prisma | PostgreSQL, MySQL, SQLite |
| TypeORM | Multiple |

## Quick Revision

- ORM = Object-Relational Mapping
- Interact with DB using objects
- Auto-generates queries
- Use for: data modeling
